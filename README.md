## 继续添加

- 新工具：复制 [条目模板](tools/_template.md)，放到 `tools/`，再加入上方目录。
- 新 skill：把完整技能目录放到 `skills/<skill-name>/`，包含 `SKILL.md` 及其引用文件，再加入目录。
- 用过之后：在对应条目补充自己的使用场景和体验。

外部项目保留原始链接、作者和许可证信息；本仓库中的示例或引用资料保留其原有归属。
