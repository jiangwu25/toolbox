## 能做什么

| Skill | 输出 |
| --- | --- |
| `paper2slides` | PPTX 幻灯片 |
| `paper2poster` | HTML / PNG 会议海报 |
| `paper2html` | 单页项目主页 |
| `paper2xhs` | 小红书图文、封面和配图 |
| `paper2wechat` | 微信公众号文章及封面 |

## 什么时候用

论文内容已经成稿，需要做组会汇报、会议展示，或准备项目主页与传播材料时。

## 使用入口

按[上游中文说明](https://github.com/QuZhan51496/paper2anything/blob/main/README.zh-CN.md)选择所需 skill，并查看当前依赖与配置要求。本条目保存项目入口，不包含上游源码；需要使用时再获取相应版本。
